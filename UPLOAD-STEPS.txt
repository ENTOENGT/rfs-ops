RFS CRM — Release Q (AI agent part A: customer replies -> missing details)
=========================================================================

Upload this after Release P.

What is new
  When a customer replies on an enquiry that still has Missing details, the AI reads the reply and shows what it found
  in a purple "Suggestions from emails" box under Missing details. Nothing changes until you tick the answers and press
  "Fill in". Then "Ask the customer by email" asks only for what is still missing.

Step 1 — Anthropic key (only once)
  1. Someone at your company opens https://console.anthropic.com, signs in, adds billing / credit,
     then API keys -> Create key. Copy the key (it starts with sk-ant-...).
  2. Netlify -> Site configuration -> Environment variables -> Add a variable:
       ANTHROPIC_API_KEY    the key (paste it yourself; do not send it to anyone)
     Scope: All scopes.

Step 2 — Database (Supabase -> SQL Editor). Run this one file:
  db/migrations/032_ai_agent.sql
  Safe to run again. Wait for "Success".

Step 3 — Code (GitHub). Upload every other file in this zip to the same paths, in ONE commit.
  Netlify then builds once (and picks up the new key).

Step 4 — Check
  Open ENQ-EXP-26-00005 (the customer has already replied). The purple box should show what the AI found
  (pickup address, weight, DG, ready date). Tick, press "Fill in", and Missing details gets shorter.
